# 阿里云函数计算（FC）部署包

把零依赖 Node 中继打包成 **FC Web 函数 · 自定义运行时**，监听容器内 `9000` 端口；
协议与 `../server.js`、`../worker.js` 完全一致，仅入口和端口不同。

## 包内容

| 文件 | 作用 |
| --- | --- |
| `server.js` | 中继服务端（内存态，不落盘） |
| `bootstrap` | 启动脚本；控制台未配启动命令时，FC 默认执行 `/code/bootstrap` |
| `package.json` | Node 工程元信息 |

## 控制台创建步骤（需实名认证的阿里云账号）

1. 开通 **函数计算 FC**，地域选离你近的（如华东 1 · 杭州 `cn-hangzhou`）。
2. 创建函数：类型选 **Web 函数**；运行环境选 **自定义运行时 · Node.js**（16 或 18）。
3. 代码方式选 **上传 ZIP**，上传本目录打包出的 `aerial-relay-fc.zip`（包根目录直接是 `server.js`）。
4. 基础配置：
   - 启动命令：`node server.js`（留空则走 `bootstrap`）
   - 监听端口：`9000`
   - 执行超时：`60` 秒（长轮询挂起 20 秒，必须 > 20）
   - 单实例并发度：`1`（中继状态在实例内存里，并发多实例会丢队列，务必设 1）
   - 内存：512 MB 即可
5. 触发器：**HTTP 触发器**，认证方式选 **无需认证**，保留公网访问 URL。
6. 创建后复制触发器公网域名，形如：
   `https://<随机串>.cn-hangzhou.fcapp.run`

## 验收

浏览器或手机打开：

```
https://<你的域名>/healthz
```

应返回 `{"ok":true,"devices":0}`。能通后把完整域名回填到：

- 电视端 `app/src/main/java/app/orchard/tv/remote/RelayClient.kt` 的 `DEFAULT_RELAY_URL`
- 遥控器 `app/src/main/assets/sheet.html` 的中继地址默认值

## 注意事项

- 状态纯内存：实例被回收/冷启动后设备登记清空，电视下次 `hello` 会自动重新登记，无需手动操作。
- 中继只转发控制类小请求；整机备份、大批量照片仍走局域网，不经中继。
- 低频使用（一台电视、一部手机）在免费/试用额度内基本不产生费用；公网出流量按 FC 计费规则另算。
- 若 `fcapp.run` 默认域名在你的网络下不可达，再在 FC 绑定自有自定义域名。
